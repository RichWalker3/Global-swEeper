How It Works

▼
  1. Connect Jira: Open the hamburger menu, enter your Jira email/token, and connect for BRD updates. Use Remember on this computer if you want Sweep to reconnect from the OS credential store after restart.
  2. Run a WA: Paste the merchant URL, choose quick or full checkout mode, then click Run Assessment.
  3. Copy the WA prompt: After Sweep crawls the site, copy the Website Assessment Prompt.
  4. Generate in Cursor: Paste the prompt into Cursor. Cursor returns the formatted WA plus a BRD Output for Sweep section.
  5. Process BRD: Paste the finished WA into the BRD Workspace, enter the top-level SOPP key, and click Process BRD.
  6. Review and send: Check the SE output notes and Status dropdowns, then click Send to Jira.
What Sweep prepares: Website evidence, third-party and red-flag signals, a Cursor-ready WA prompt, and a BRD table that updates Jira SE Scoping Output plus Done/Canceled status.
